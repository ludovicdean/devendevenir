En début de reconversion, j’ai suivi un module d’une semaine consacré à un langage souvent sous-estimé et rarement étudié en profondeur : HTML. Il ne s’agit pas d’un langage de programmation comme Java ou C#, mais d’un langage de balisage. C’est pourtant lui que nous côtoyons le plus souvent au quotidien, puisqu’il structure les pages web que nous consultons. Il mérite donc qu’on s’y attarde.

## Les origines

À l’origine de HTML, on retrouve Tim Berners-Lee, le créateur du World Wide Web. Alors qu’il travaillait au CERN, il a imaginé un système permettant de structurer et de relier des documents grâce à des hyperliens.

Pour créer le HTML, il s’est notamment inspiré du SGML (Standard Generalized Markup Language) et d’un format de documentation utilisé au CERN. Entre 1989 et 1991, il a posé les premières bases du Web et développé les outils nécessaires à son fonctionnement.

En 1991, il a mis à disposition [le premier site web](https://info.cern.ch/). Ce site est consacré au projet World Wide Web lui-même. Il explique notamment le fonctionnement de l’hypertexte ainsi que la manière de créer et d’utiliser des pages web.

## Que signifie HTML ?

HTML signifie HyperText Markup Language, ou « langage de balisage d’hypertexte » en français.

Le terme « balisage » désigne la manière dont on utilise des balises pour décrire la structure et le rôle d’un contenu. Le terme « hypertexte » désigne quant à lui un document contenant des liens permettant de naviguer vers d’autres documents ou ressources.

Contrairement à un document classique, que l’on parcourt généralement de manière linéaire, un hypertexte permet de suivre différents chemins grâce aux hyperliens.

## Le rôle du HTML
HTML sert à structurer le contenu d’un document selon le rôle de chaque élément : titre, paragraphe, lien, image ou liste, par exemple. Le revers de la médaille est le fait que le HTML ne gère absolument pas la mise en forme du contenu.

Prenons l'exemple d'une page web réduite à sa plus simple expression comme l'extrait de code suivant :


```html
<!doctype html>
<html lang="fr">
  <head>
    <title>Exemple HTML</title>
  </head>
  <body>
    <h1>Bonjour</h1>
    <p>Bienvenue sur mon blog !</p>
  </body>
</html>
```

La page web affichée est certes structurée, mais elle n'est pas du tout esthétique. C'est ce qu'on aperçoit parfois quand un site web a un problème et s'ouvre sans avoir chargé les ressources permettant d'apporter la part esthétique du site web.

Les éléments qui composent cet extrait de code sont appelés balises.

## Niveau 1 : la structure d'une page HTML

Voici le sens de chaque balise dans l'extrait présenté juste au-dessus :

- `<!doctype html>` indique au navigateur qu'il doit interpréter le document en mode standard (et non en mode de compatibilité). 
- `<html>` est la racine du document HTML. 
- `<head>` contient les métadonnées du document ainsi que les ressources qui lui sont associées. 
- `<body>`, c'est elle qui porte le contenu de la page. 
- `<h1>` est la balise de titre de niveau 1.
- `<p>` est la balise de paragraphe.

Quand on regarde ce code, on remarque que beaucoup de balises apparaissent plusieurs fois et se ressemblent. Voici les éléments qui composent une balise :

```html
<nom_de_la_balise>contenu_de_la_balise</nom_de_la_balise>
```

La première balise est appelée balise ouvrante, la seconde est appelée balise fermante. Ce qui se trouve entre ces deux balises constitue son contenu. C'est généralement la partie visible par l'utilisateur. Si vous reprenez le code et la capture d'écran plus haut, vous remarquerez que les éléments visibles de la page web sont ceux qui sont entre les balises `<h1>` et `</h1>`, et `<p>` et `</p>`.

Vous me direz peut-être "Pourquoi on ne voit pas le contenu de la balise `<title>` ?". Le title est une balise qui contient le texte de l'onglet du navigateur. C'est le texte qui vous permet de savoir que le douzième onglet en partant de la gauche c'est votre blog tech préféré, Dev En Devenir.

La balise `head` contient quant à elle les métadonnées de la page. Les métadonnées sont les informations qui décrivent la page, comme son titre, les liens vers les ressources CSS et JavaScript, ou encore les informations qui permettent de partager votre page sur les réseaux sociaux avec un titre, une description et une image spécifique.

Toutes les balises ne se ressemblent pas. Certaines sont invisibles aux utilisateurs, d'autres sont visibles. Par ailleurs, certaines balises sont auto-fermantes, comme la balise image `<img>`.

Aux éléments présentés plus haut il faut ajouter les balises `header`, `main` et `footer`. Avec ces balises, on peut commencer à s'intéresser à la sémantique d'une page HTML.

## Niveau 2 : la sémantique d'une page HTML

Le header correspond à l'en-tête de la page, le main correspond au contenu principal de la page et le footer correspond au pied de page. Ces balises sont toutes les trois imbriquées dans la balise `body`.

Le nom des balises n'est pas choisi au hasard. Chaque balise a un rôle précis, et ce rôle est précisément porté par le nom de la balise. Examinons maintenant le corps de la page suivante :

```html
<body>
  <header>
    <nav>
      <a href="/">Accueil</a>
      <a href="/articles">Articles</a>
    </nav>
  </header>

  <main>
    <article>
      <h1>Comprendre HTML</h1>

      <p>
        HTML permet de structurer le contenu d'une page web.
      </p>

      <h2>Les notions importantes</h2>

      <p>
        Une page HTML est composée d'éléments imbriqués les uns dans les autres.
      </p>
    </article>
  </main>

  <footer>
    <p>Publié sur DevEnDevenir.</p>
  </footer>
</body>
```

Les éléments présents ont tous un rôle précis dans la structure de la page :

- `<header>` : l'en-tête d'une page (ou d'une section).
- `<nav>` : regroupe les principaux liens de navigation.
- `<a>` : lien vers une autre page.
- `<main>` : contient le contenu principal de la page. Un document ne doit généralement contenir qu'un seul élément `<main>`.
- `<article>` : désigne un contenu autonome, réutilisable séparément du reste de la page.
- `<h1>` : titre principal de la page. Il est généralement unique sur une page HTML. Il ne faut pas le confondre avec `<title>`, qui décrit le document dans l’onglet du navigateur.
- `<h2>` : un titre de niveau 2 (il existe 6 niveaux de titres, de `<h1>` à `<h6>`).
- `<footer>` : le pied de page d'une page (ou d'une section).

Le respect de la sémantique est important pour l'accessibilité (les lecteurs d'écran), le référencement naturel (SEO, bien que les choses bougent vite dans ce domaine, notamment avec l'IA) ainsi que pour la lisibilité du code. Quand une balise a pour seul rôle de permettre de gérer la mise en forme d'un élément, on utilise une balise particulière, la balise `div`. Elle permet de grouper des éléments afin de gérer leur mise en forme en prenant en compte tout leur contenu simultanément. Cette balise n'a aucun effet sur le contenu de la page tant qu'elle n'est pas mise en forme par du CSS.

Souvent, quand la balise `div` est trop fréquemment utilisée dans une page web, on parle de soupe de div. L'utilisation trop fréquente de cette balise fait disparaître la sémantique de la page, et rend la lisibilité du code difficile. Un lecteur d'écran ne sera pas en mesure d'interpréter la page correctement, et donc de la restituer.
