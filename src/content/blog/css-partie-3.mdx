## Les unités

`px` pour une bordure fine, `rem` pour le texte, `%` et `fr` pour les colonnes.

## Le responsive

Une media query, mobile d'abord : la grille de la partie 2 passe d'une colonne à deux.

## Les propriétés personnalisées

Une couleur et un espacement déclarés une fois sur `:root`, réutilisés dans les règles déjà écrites.

## Les pseudo-classes du quotidien

`:hover`, `:focus-visible`, `:nth-child`, sur les liens et les cartes de la page.

## La suite

Tailwind et PicoCSS, déjà traités sur le blog, comme étape d'après : ils produisent le CSS qu'on vient d'écrire à la main.
